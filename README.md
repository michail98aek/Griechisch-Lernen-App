# Griechisch lernen mit Mia

Eine kleine Lern-App fürs griechische Alphabet mit Katzen-Maskottchen.

## Lokal testen
npm install
npm run dev

## Für Claude Code: was als Nächstes zu tun ist
1. `npm install` ausführen
2. Kostenlos hosten, z. B. mit Vercel:
   npm install -g vercel
   vercel
   (den Anweisungen folgen, am Ende gibt es einen Link zur fertigen App)
3. Alternativ: Projekt auf GitHub pushen und dort mit Vercel oder Netlify verbinden
   (automatisches Deployment bei jeder Änderung)
4. Optional: eigenes App-Icon in `manifest.json` ergänzen, damit "Zum Home-Bildschirm
   hinzufügen" auf dem Handy ein schönes Icon zeigt statt des Standard-Icons
5. Fortschritt wird über localStorage im Browser gespeichert (pro Gerät/Browser)
